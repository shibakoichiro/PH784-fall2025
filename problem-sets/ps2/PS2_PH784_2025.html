# 2. Causal Inference Under Conditional Exchangeability

Next, consider an observational study to examine the effect of poverty on depression. The `poverty` in the `NHANES` is a continuous variable for the ratio of household income compared to poverty threshold. A team of epidemiologists decided to dichotomize this variable and create `poverty.bin` using 1 as a cutoff. That is, `poverty.bin=1` for `poverty<=1` (i.e., below the poverty guideline) and `poverty.bin=0` otherwise.

The variable `Depressed` in `NHANES` has three categories ("None", "Several","Most"), which was treated as a binary outcome (`Depressed.bin`) where `Depressed.bin=0` when `Depressed=="None"` and otherwise `Depressed.bin=1`.

They performed logistic regression of `Depressed.bin` on `poverty.bin`, adjusting for age, gender, race, and education. Assume that the conditional exchangeability assumption holds after adjusting for these covariates. 

```{r}
NHANES |> 
  mutate(Depressed.bin = ifelse(Depressed == "None",0,1)) |> 
  mutate(poverty.bin = ifelse(Poverty <= 1, 1, 0)) |> 
  mutate(Race1 = factor(Race1, ordered = F) |> 
  relevel(Race1, ref = "White")) |> 
  glm(formula = Depressed.bin ~ poverty.bin + Age + Gender + Race1 + Education, family="binomial") |> 
  tbl_regression(exponentiate = T) 
```

Now, assume that `poverty.bin` is rare and the estimated odds ratios approximate risk ratios. This is actually not the case in the data, but let's make this assumption for simplicity. The risk ratio for `poverty.bin` is written as:

$\frac{Pr[Depressed.bin=1|Poverty.bin=1, Age, Gender, Race, Education]}{Pr[Depressed.bin=1|Poverty.bin=0, Age, Gender, Race, Education]}$

Under the identification assumptions, this corresponds to the causal estimand of:

$\frac{Pr[Depressed.bin^{Poverty.bin=1}=1|Age, Gender, Race, Education]}{Pr[Depressed.bin^{Poverty.bin=0}=1|Age, Gender, Race, Education]}$
