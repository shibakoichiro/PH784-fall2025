Panel data analysis

In this problem set, we will use the data WageData from the R package panelr.

These data come from the years 1976-1982 in the Panel Study of Income Dynamics (PSID), with information about the demographics and earnings of 595 individuals.

This dataset includes the following variables:

  • id: Unique identifier for each survey respondent
  • t: A number corresponding to each wave of the survey, 1 through 7
  • lwage: Natural logarithm of earnings in the past year
  • union: Binary indicator of whether respondent is a member of a union (1 = union member)
  • wks: Weeks worked in the past year
  • ms: Binary indicator of whether respondent is married (1 = married)
  • fem: Binary indicator of whether respondent is female (= 1)
  • blk: Binary indicator of whether respondent is African-American (= 1)
  • ed: Years of education

Note that this dataset is in a “long” format (i.e., each row represents a person-wave observation), and each individual id has multiple rows for different t.

# Panel data analysis

```{r}
pacman::p_load(tidyverse, broom, tinytable, panelr)
```

In this problem set, we will use the data `WageData` from the R package `panelr`.

> These data come from the years 1976-1982 in the Panel Study of Income Dynamics (PSID), with
information about the demographics and earnings of 595 individuals.

This dataset includes the following variables:

- `id`: Unique identifier for each survey respondent
- `t`: A number corresponding to each wave of the survey, 1 through 7
- `lwage`: Natural logarithm of earnings in the past year
- `union`: Binary indicator of whether respondent is a member of a union (1 = union member)
- `wks`: Weeks worked in the past year
- `ms`: Binary indicator of whether respondent is married (1 = married)
- `fem`: Binary indicator of whether respondent is female (= 1)
- `blk`: Binary indicator of whether respondent is African-American (= 1)
- `ed`: Years of education

Note that this dataset is in a "long" format (i.e., each row represents a person-wave observation), and each individual `id` has multiple rows for different `t`.

Let's say we want to estimate **the effect of union membership (`union`) on earnings (`lwage`)**. After carefully selecting covariates, we fit the following regression model (see the line for `lm()`). 

```{r}
#| code-fold: FALSE

WageData |> 
  lm(formula = lwage ~ union + wks + ms + fem + blk + ed + t) |> 
  tidy(conf.int=T) |> 
  select(term, estimate, conf.low, conf.high, p.value) |>
  mutate(p.value = ifelse(p.value < 0.001, "<.001", as.character(round(p.value, 3)))) |> 
  tt(caption = "Model 1") |> 
  format_tt(digits = 2, num_fmt = "significant_cell")
```


Now consider a different approach to model this data. The following code uses the `lm()` to fit a different model for the relationship `union` and `lwage`. Notice that the following table only shows the first estimates of the regression output by using the `slice(1:4)`.

```{r}
#| code-fold: FALSE

WageData |> 
  lm(formula = lwage ~ union + wks + ms + as.factor(id))  |> 
  tidy(conf.int=T) |> 
  select(term, estimate, conf.low, conf.high, p.value) |> 
  slice(1:4) |> 
  tt(caption = "Model 2") |> 
  format_tt(digits = 2, num_fmt = "significant_cell")
```
